# stock-analysis-v1

A project for performing fundamental analysis on U.S. stocks using an existing stock screener. The screener is designed to identify bullish trends and all-time highs (ATH), and this repository adds analysis tools to support investment research.

## Features

- Fundamental stock analysis for U.S. market data
- Built around a stock screener with bullish trend detection
- Supports identification of all-time high (ATH) stock conditions

## Notes

- This repository focuses on combining technical screening with fundamental evaluation.
- The project is intended for U.S. equities.
